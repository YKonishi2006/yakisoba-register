# 焼きそばレジ

NPO法人voluntas の MURP お祭りで焼きそばを販売するための、タブレット用レジWebアプリ。
ビルド不要の静的サイトで、GitHub Pages にそのまま置けます。ホーム画面に追加すると電波がなくても起動します（PWA）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・会計フロー・localStorage の形式は元の `yakisoba-register.html` と同じ） |
| `sw.js` | Service Worker。アプリ本体をキャッシュしてオフライン起動させる（フォントは端末の標準フォントを使うので外部読み込みなし） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面表示の設定 |
| `icons/` | アプリアイコン（SVG と PNG 180/192/512） |
| `.nojekyll` | GitHub Pages で Jekyll 処理を無効にする |

## 会計のしかた

「販売」タブの1画面で会計が終わります（左＝注文リストと合計、右＝商品・お預り金額とテンキー・会計ボタン）。

1. **商品**（紅なし／紅あり）をタップ。押した数が右上に出る。数の調整は注文リストの −／＋。
2. 受け取った額を入れる。
   - テンキーで金額を打つ（例：1 → 000）。
   - 右列の **+¥10,000／+¥5,000／+¥1,000** は押すたびに足し算（+¥1,000 を2回で ¥2,000）。
   - ぴったり受け取ったときは、何も入れずに **「ちょうどで会計」** を押すだけでよい。
   - 足りないと「不足」が赤で出て、会計ボタンが押せない。入れ直すときはお預り金額の左の ⊗。
3. **会計する** → お釣りが画面いっぱいに大きく出る。
4. 次のお客様の**商品をタップすると、そのまま次の会計**が始まる（「次のお客様」ボタンでも可）。

いちばん多い「1食・千円札」は **紅なし → +¥1,000 → 会計する** の3タップ。
PCで使うときは、数字キー・Backspace・Enter（会計）・Esc（お預りを消す）も使えます。
会計直後に打ち間違いに気づいたら **「訂正」**：その取引を取消扱いにして、注文と預りを戻した状態からやり直せます（取引履歴には取消として残る）。

## トレーニングモード（練習用）

設定タブ → トレーニングモードの **「開始する」**。

- 画面が赤枠で囲まれ、上に「トレーニングモード中」の赤い帯が出る。
- 会計・取消・履歴・精算・価格変更・CSVなど、すべて本番と同じように試せる（CSVのファイル名は `training_` で始まる）。
- 練習の記録は本番とは別に保存されるので、本番の売上記録には一切残らない。
- 赤い帯の **「終了する」**（または設定タブ）→ 確認して終了すると、**練習の記録はすべて消え**、本番の画面に戻る。
- 開始時の価格・目標・原価は本番の設定を引き継ぐ。

## 価格を変えるとき

設定タブ → 販売価格の **「変更」** → 新しい金額を入れて **「変更する」**。

- 変えた時刻と「¥500 → ¥400」が取引履歴に青い行で残る（CSVにも出る）。
- 各取引には当時の単価が保存されるので、それまでの売上は変わらない。
- 2つ以上の単価で売ったときは、精算タブに単価別の食数・売上が出る。

キーを押すと短い音が鳴ります（Android ではバイブも）。設定タブで切れます。

## 元の版からの変更点

- **レジ画面の作り直し**：預り金入力・お釣り表示のポップアップをやめ、1画面で完結するレジ式に（上記「会計のしかた」）。
- **見た目をシンプルに**：iPad の POS アプリに近い白基調。文字は端末の標準フォント（本文17px以上）、色は意味のあるところだけ（商品＝緑/赤のライン、会計ボタン＝青、不足＝赤）。ライト／ダーク両対応。「元が取れるまで」の表示は精算タブへ移動。
- **PWA化**：manifest・Service Worker・アイコンを追加。初回に電波のある場所で一度開けば、以後はオフラインでも起動できる。
- **CSVエクスポート**：「取引履歴」と「精算」タブに `CSVで保存` ボタン。全取引（取消分も「取消」と明記）と、末尾に集計（取消除く）を出力。Excelで文字化けしないよう BOM 付き UTF-8。ファイル名は `yakisoba_YYYYMMDD_HHMM.csv`。
- **単体HTMLとして動くよう修正**：`<!doctype>`・`charset`・`viewport` を追加。`[hidden]{display:none!important}` を追加（これが無いと会計シートが閉じず、お釣り画面の裏に残っていた）。
- 画面スリープ防止を、アプリに戻ってきたときに取り直すようにした。
- 電波が切れているとヘッダーに「オフライン」と表示。

- **価格変更の記録**：取引ごとに単価（`price`）を保存し、価格変更を `priceLog` に記録。取引履歴・CSV・精算（単価別）に反映。
- **目標達成率**を半円ゲージで表示。

localStorage のキー（`yakisoba-register-v1`）は同じです。データには `tx[].price` と `priceLog` を追加しましたが、これらが無い古い記録もそのまま読めます（単価は 合計÷食数 で補う）。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`yakisoba-register`）。
2. このフォルダの中身をプッシュする。

   ```bash
   git init
   git add .
   git commit -m "焼きそばレジ"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/yakisoba-register.git
   git push -u origin main
   ```

3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存。
4. 1〜2分後に `https://<ユーザー名>.github.io/yakisoba-register/` で開ける。

## タブレットへのインストール

- **iPad（Safari）**：URL を開く → 共有ボタン → 「ホーム画面に追加」。
- **Android（Chrome）**：URL を開く → メニュー → 「アプリをインストール」または「ホーム画面に追加」。

インストール後、**一度アプリとして起動してから**機内モードにして起動できるか確認しておくと安心です。

> 記録は端末ごとのブラウザ内に保存されます。Safari で開いたページと、ホーム画面に追加したアプリでは保存場所が別になる（特に iPad）ので、当日はどちらか一方だけを使ってください。

## 更新するとき

`index.html` などを書き換えたら、`sw.js` 先頭の `VERSION` を上げてからプッシュします（例：`"v1"` → `"v2"`）。
タブレット側は、電波のある場所でアプリを**2回**開くと新しい版に切り替わります（1回目で裏で取得、2回目で反映）。

## ローカルで確認する

```bash
python -m http.server 5173
```

`http://localhost:5173/` を開く（Service Worker は `file://` では動かないため、サーバー経由で開く）。
